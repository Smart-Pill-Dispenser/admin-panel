# Navos ZET · Admin Panel

Admin panel for the Navos ZET platform — devices, caregivers, system config, help & support, logs.

## Run locally

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```

## Tech

- Vite, TypeScript, React, React Router
- shadcn-ui, Tailwind CSS
- TanStack Query, Recharts
